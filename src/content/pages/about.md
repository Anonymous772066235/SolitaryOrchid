## 在折腾什么

方向是三维数据处理与可视化：点云、mesh、坐标变换、渲染管线里那些既数学又工程的问题。日常写代码，偶尔写点笔记，把踩过的坑记下来。

## 时间线

- **2019.11** 这个站第一次上线，是本科 Web 前端课的作业，模板主页加几个爱好展示页
- **2024.12** 重新激活，打算当成个人博客的雏形
- **2026.06** 换掉旧版 jQuery，补齐安全更新
- **2026.11** 重构为内容站：文章系统、构建脚本、几个小彩蛋

## 兴趣

小说、音乐、电影、涂鸦、摄影、编程。对应的几个页面都在导航里，随时可以逛。

## 关于这个站

- 手写 HTML / CSS / JS，配一个构建脚本把 Markdown 生成静态页
- 不使用前端框架，访客端只加载一个约 10 KB 的 `site.js`
- 托管于 GitHub Pages，支持 RSS 订阅

站点内容以笔记与生活记录为主，欢迎交流。
