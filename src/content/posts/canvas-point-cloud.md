首页背景那团缓慢旋转的点云，没有用 WebGL，也没有引入图形库——它只是把三维点做了一次旋转和透视除法，然后画成小圆点。

## 三维点从哪来

球面均匀采样最省事的做法是先随机一个 `u ∈ [-1, 1]`，再随机一个角度 `θ`：

```text
r = sqrt(1 - u²)
x = r · cos(θ)
y = u
z = r · sin(θ)
```

这样点会均匀铺在球面上，而不是在两极堆叠。为了让形状更像「点云」而不是「毛球」，我又补了一圈半径略大的环状点，压扁在赤道附近。

## 旋转与投影

绕 Y 轴旋转只需要两个三角函数：

```text
x' = x·cos(t) - z·sin(t)
z' = x·sin(t) + z·cos(t)
```

再绕 X 轴倾斜一点，让画面有俯视感。投影用最简单的透视：

```text
persp = d / (d + z')
sx = cx + x' · scale · persp
sy = cy + y' · scale · persp
```

`d` 是相机距离，取一个大于最大节点距离的值，避免除以零。

## 深度决定顺序与亮度

真正的三维渲染要按深度排序、做遮挡。这里只要「看起来像那么回事」，所以不排序，改用两件事表达远近：

- 半径：`size = base · persp`，近处大、远处小
- 透明度与色相：越近越亮、越偏冷色

```text
depth = clamp((1 - z' / 2.2) / 2, 0, 1)
alpha = 0.16 + depth · 0.75
hue   = 218 + depth · 52
```

## 性能上的取舍

- 点数控制在 900 以内，`requestAnimationFrame` 每帧只做三角函数与 `arc`，没有对象分配
- 用 `devicePixelRatio` 缩放画布，最多取 2 倍，避免高分屏上过于昂贵的填充
- 尊重 `prefers-reduced-motion`：用户关闭动画时只渲染一帧静态点云

如果哪天想要真正的遮挡关系、法线与光照，那就得换 WebGL（Three.js 或原生着色器）；但对一个装饰性的背景而言，Canvas 2D 的性价比高得多。
